# 🛒 Basic E-Shop Website

A simple and responsive e-shop website built using **HTML**, **CSS**, **PHP**, and **Bootstrap**.  
This project demonstrates the fundamentals of an online shopping platform including product listings, responsive UI, and basic backend functionality with PHP.

---

## 🚀 Features

- Responsive design using Bootstrap
- Product listing page
- Shopping cart UI
- Simple PHP backend structure
- Clean and modern interface
- Easy to customize and expand

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- PHP
- Bootstrap v3.3

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/GeorgeKonstanto/basic-eshop.git
```

2. Move the project folder to your local server directory:

- **XAMPP:** `htdocs`

3. Start Apache and MySQL from your control panel.

4. Open your browser and visit:

```bash
http://localhost/basic-eshop
```

---

## 🎨 Customization

You can easily customize:

- Colors and styles in `css/style.css`
- Layout components using Bootstrap classes
- Product data inside PHP files or database
- Images inside the `images/` folder
